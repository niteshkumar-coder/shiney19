# 🎂 Shiney 19 – Birthday Surprise Website 💗

A beautiful, interactive and personalized birthday surprise website created to celebrate Shiney's 19th Birthday on **18 November 2026**.

This project transforms a simple birthday wish into a magical digital experience with animated gift opening, Java-style code execution, glowing fireworks, birthday music and personalized messages.

## ✨ Features

- 🎁 **Interactive Gift Opening** – A beautiful animated gift box that reveals the surprise.
- 💻 **Java Code Animation** – A programming-themed birthday surprise with animated code execution.
- 🎉 **Grand Birthday Celebration** – Colorful fireworks, confetti, balloons and glowing effects.
- 🎂 **19th Birthday Celebration** – Special birthday reveal for Shiney.
- ⏳ **Live Age Counter** – Displays years, days, hours, minutes and seconds.
- 💌 **Personalized Birthday Message** – A special birthday greeting.
- 🎵 **Background Music Player** – Interactive music controls with play and pause.
- 💗 **Animated UI** – Floating hearts, glowing text and smooth transitions.
- 👆 **Interactive Pointer Guide** – Guides visitors through the surprise.
- 📱 **Responsive Design** – Optimized for desktop and mobile devices.
- ⬇️ **Automatic Smooth Scrolling** – Helps visitors navigate through birthday sections.

## 🛠️ Tech Stack

- React 19
- TypeScript
- Vite 8
- Tailwind CSS 4
- Framer Motion / Motion
- Lucide React
- HTML5 Audio
- CSS Animations

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/niteshkumar-coder/shiney19.git
```

### 2. Open the Project

```bash
cd shiney19
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
